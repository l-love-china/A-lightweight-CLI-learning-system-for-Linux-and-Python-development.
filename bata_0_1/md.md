# Python 类操作系统 - 命令行工具

## 项目简介

这是一个用Python编写的简单命令行工具，主要用于学习Python命令行工具的编写。它类似于一个子操作系统，可以运行Python程序并调用系统的Python解释器。

## 功能特性

- **Python程序执行**: 可以直接运行Python脚本和程序
- **系统Python调用**: 能够调用系统中安装的Python解释器
- **命令行交互**: 提供友好的命令行界面
- **学习工具**: 适合Python初学者学习命令行工具开发

## 使用方法

### 基本运行
```bash
python main.py
```

### 运行Python程序
```bash
# 在命令行工具中执行Python脚本
run python_script.py
```

### 调用系统Python
```bash
# 调用系统Python解释器
system_python
```
